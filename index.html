Proyectos Destacados

Aeropuertos Americanos

Descripción del Proyecto Este proyecto es un sistema web para AeropuertosAmericanos, una empresa que gestiona aeropuertos, vuelos y la venta de pasajes en América. El sistema permitirá la gestión de ciudades, aeropuertos, vuelos y clientes, además de proporcionar funcionalidades para la compra y venta de pasajes. Descarga: https://github.com/AnderCodex/AeropuertosAmericanos.git

Sistema de Gestión de Solicitudes de Consultas para Mutualista

Sistema web para gestionar solicitudes de consultas en una mutualista. Permite administrar empleados, policlínicas, consultorios, pacientes, consultas y solicitudes. Incluye autenticación, asignación de números, marcación de asistencia y estadísticas. Desarrollado en .NET Framework 4.5.2/4.6 con SQL Server y Entity Framework Database First. Descarga: https://github.com/AnderCodex/Sist-de-Gestion-de-Solicitudes-Consultorio.git

Sistema de Ventas "Farmacia"

El proyecto es un sistema de ventas para una farmacia con dos interfaces web: un sitio ASP.NET público para visualizar artículos y una aplicación MVC para empleados que gestiona categorías, clientes y ventas. Usa .NET, C#, SQL Server y arquitectura en 3 capas. Incluye autenticación, CRUD, historial de estados y seguimiento de entregas. Descarga: https://github.com/AnderCodex/Sistema-de-Ventas.git
